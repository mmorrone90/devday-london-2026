# Asset sources

KitBitz identifies its [Halloween Kit](https://kitbitz.art/kits/halloween-kit) as free CC0 illustrations. Assets were found through its public read only MCP endpoint, https://mcp.kitbitz.art, and downloaded from its asset CDN on 1 November 2026.

| Local asset | KitBitz source name |
| --- | --- |
| public/assets/kitbitz/pumpkin.png | Pumpkin head 2 |
| public/assets/kitbitz/pumpkin-glow.png | Pumpkin head light |
| public/assets/kitbitz/ghost.png | Ghost 1 |
| public/assets/kitbitz/ghost-friendly.png | Ghost 2 |
| public/assets/kitbitz/ghost-playful.png | Ghost 3 |
| public/assets/kitbitz/reaper.png | The Black Reaper |

These are original PNG illustrations, not 3D meshes. Animation and billboard placement are implemented in Three.js. No KitBitz application or MCP source code is bundled.

Procedural architectural textures, skull medallions, flowers and environment geometry were authored for AFTERLIFE. The visual target in docs/visual-target.png was generated from the user's approved art direction.
